Model Architecture

π0.5 — Vision-Language-Action

π0.5 is built on PaliGemma (Google's 3B VLM) with an added 300M action expert that communicates via cross-attention at every transformer layer. It generates actions through flow matching — a continuous diffusion process that denoises a chunk of Gaussian noise into a 1-second action sequence.

Flow Matching Loss

At each training step a random timestep t ∈ [0, 1] is sampled. The clean action is linearly interpolated with Gaussian noise to produce a noisy action xt. The model predicts the velocity field that maps noise back to the clean action:

xt = t · ε + (1 − t) · a
ut = ε − a
ℒ = MSE(vθ(xt, t, obs), ut)

At inference, 10 Euler denoising steps integrate the velocity field from t=1 to t=0, producing a 10-step action chunk.

Joints 1–6 interpolate from home to approach configuration at the fixed shoulder angle, descending toward the workspace.

Phase 1 ≤ 600 steps

Shoulder sweeps continuously in −Y, arm pushes the cube across the table. Episode terminates early on success.

Baxter Gripper & Scripted Pick Demo

To support future pick-and-place VLA inference, the Baxter MJCF was extended with full Rethink Electric Parallel-Jaw Grippers and a scripted 4-phase pick demo was developed using Damped Least-Squares Jacobian IK.

Gripper MJCF

The original model used placeholder spheres. The new model adds the full Rethink gripper kinematic chain — connector plate, gripper base, and two finger links with slide joints in the gripper-Y axis.

Pick Sequence

Phase 0

Settle simulation, open gripper.

Phase 1

Joint-space P control to Q_REACH — orients fingers horizontally (closing in ±Y) with ~20 mm clearance above table.

Phase 2

Cartesian DLS IK centers grip site over cube in X/Y. Fingers straddle cube faces symmetrically.

Phase 3

Close gripper — fingers contact cube faces in ±Y.

Phase 4

Cartesian DLS IK lifts 22 cm. Cube rises with arm — pick successful.

IK Design

Pure pseudoinverse IK fails near joint limits on large motions. The pick demo uses Damped Least-Squares (DLS) IK with a null-space term that keeps the arm near a reference configuration:

Jdls = Jᵀ (JJᵀ + λ²I)⁻¹
q̇ = Jdls · Kp · ecart
    + (I − JdlsJ) · Knull · (qref − q)
DLS damping λ0.05
Cartesian gain Kp5.0
Null-space gain2.0
Velocity limit±1.5 rad/s
Substeps8 per viewer sync

Gripper Orientation Key Insight

The w2 wrist-roll joint was swept analytically to find the configuration where the gripper Y-axis (finger-closing direction) is nearly horizontal (z-component ≈ 0.005). Without this, the fingers close diagonally and the cube slips vertically out of the grip.

Key Findings

✅

Structured Motion

The policy produces task-relevant motion, not random noise. Shoulder and elbow dominate; wrist joints are correctly suppressed. Action magnitude ramps up monotonically — the model commits to the push trajectory with increasing confidence.

✅

Clean Convergence

Loss dropped 67.4% over 20k steps. Only 3 gradient clips in 198 logged steps, all in the first 1k. Param norm drifted just +0.4% — the pre-trained base model is essentially intact; only the LoRA adapters changed.

⚠️→✅

Language Conditioning Collapse → Resolved

In run_001, changing the prompt (e.g., "wave your hand") produced identical cube-push motion — the visual scene alone drove the action. run_002 addresses this directly by training on three tasks with distinct behaviours, forcing the model to use the language prompt to discriminate. With 230 demos across three prompts, language grounding is restored.

✅

Efficient Fine-tuning

LoRA (rank 16) reduced GPU memory from ~50 GB (full FT) to ~17 GB, enabling training on a single RTX 5090. The async checkpoint OOM bug was resolved by switching to synchronous writes and closing background applications.
